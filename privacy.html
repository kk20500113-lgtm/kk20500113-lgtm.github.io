Hermes Task Sync — Privacy Policy

Hermes Task Sync is a personal, single-user tool that synchronizes the user's own Google Tasks with their local notes.

  • It stores no data on any server; all processing happens on the user's own computer.
  • It requests only the Google Tasks scope, used solely to read and write the user's own tasks.
  • OAuth tokens remain on the user's device and are never shared.
